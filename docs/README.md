# راهنمای مستندات پروژه

این پوشه شامل چند فایل `md` جداگانه برای بک‌اند و فرانت‌اند است تا خواندن و جستجو راحت‌تر شود.

## Backend
1. `01-backend-overview.md` : شروع برنامه، دیتابیس، Auth/Authorization
2. `02-backend-routes.md` : لیست روت‌ها و اتصال‌شان به کنترلرها
3. `03-backend-controllers.md` : مسئولیت هر کنترلر (چه کاری انجام می‌دهد)
4. `04-backend-services-utils.md` : میدل‌ویرها، سرویس‌ها (منطق اصلی) و utilها

## Frontend
1. `11-frontend-overview.md` : Entry point، API wrapper، Theme
2. `12-frontend-pages.md` : توضیح هر Page و endpointهای مصرفی
3. `13-frontend-components.md` : کامپوننت‌ها/هوک‌های مشترک و UI components
